EvolveRouter — The Routing Formula

Every term traces back to a named quantity. Flywheel and exploration can only fine-tune — the decision model's judgment is the ceiling.

1 · Composite score

$$\text{score}(m) = \underbrace{\Big[\textstyle\sum_k W_k \cdot f_k(m)\Big]}_{\text{five factors}} \times \underbrace{B(m)}_{\text{flywheel bias}} \times \underbrace{P(m)}_{\text{budget damp}} \times \underbrace{\big(1 + 0.15\,c_r\big)}_{\text{advisor bonus}}$$
Q quality+ S speed+ C cost+ R reliability+ H headroom

2 · Dynamic weights difficulty-linked × quota-aware (BaRP Eq.1)

$$\mathbf{W} = \operatorname{norm}\Big(\underbrace{\mathbf{w}^{\,\mathrm{diff}}(d_{\mathrm{eff}})}_{\text{hard tasks}\,\Rightarrow\,\text{quality}\uparrow} \odot \underbrace{\mathbf{w}^{\,\mathrm{quota}}(t)}_{\text{tight quota}\,\Rightarrow\,W_c(1+1.5t),\,W_q(1-0.25t)}\Big), \quad t \in [0,1]$$
t = fraction of candidates whose remaining quota < 8× estimated tokens. No quota data → no adjustment.

3 · Thompson exploration BayesianRouter Eqs.4–6 — uncertainty-driven, self-converging

$$\mu_0 = 0.15 + 0.70\,\mathrm{rank}(q), \qquad \alpha = \mu_0\nu_0 + s, \quad \beta = (1-\mu_0)\nu_0 + f, \quad \nu_0 = 8$$ $$\tilde{\theta} \sim \mathrm{Beta}(\alpha, \beta), \qquad \text{score} \times \Big(1 + \rho\,3\,(\tilde{\theta} - \mathbb{E}[\theta])\Big), \qquad \rho = \texttt{explore\_ratio}$$
Wide posterior (few samples) → large offset → explore more; narrow posterior → converge. μ₀ uses the relative rank of the Jev quality factor across candidates (absolute q saturates near 1.0 and would kill exploration).

4 · Flywheel learned bias two-stage normalization (BayesianRouter App.B) + baseline-relative update (BaRP Eq.6)

$$\operatorname{norm}(v) = \operatorname{clamp}\!\left(\frac{v - \bar{x}}{q_{80} - q_{20}},\ 0,\ 1\right) \qquad \mathrm{reward} = w_{\mathrm{ok}}\cdot\operatorname{norm}(\mathrm{ok}) + (1{-}w_{\mathrm{ok}})\cdot\big(1 - \operatorname{norm}(\ln t)\big)$$ $$B(m) = \operatorname{clamp}\Big(1 + \big(\mathrm{reward}(m) - \operatorname*{median}_{m'}\mathrm{reward}(m')\big)\cdot\gamma,\ 0.7,\ 1.3\Big)$$
Two-stage: subtract the rolling mean, scale by the 20/80 inter-quantile range. Baseline-relative: the flywheel learns advantage over the cross-model median, not absolute outcomes — workload drift never leaks into bias. Flywheel only fine-tunes: |bias| ≤ 1.3.

5 · Decision pipeline

digest signals→ sticky check→ dual judge (Jev + heuristic, take-conservative)→ advisor top-8 (anonymized)→ hard filters→ dynamic weights→ score→ Thompson explore→ route + chain(3) + quality cascade→ outcome → flywheel
Failure anywhere in judge / advisor / distill / cascade never blocks routing. Learning only from bandit feedback on chosen models.
